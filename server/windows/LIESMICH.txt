WealthFlow-Server
=================

Inhalt dieses Ordners
  start.cmd                 Startet den Server (Doppelklick).
  bin\wealthflow_server.exe Das Server-Programm.
  lib\sqlite3.dll           Die Datenbank-Bibliothek (SQLite).
  web\                      Die Web-Version für den Browser.
  daten\                    Entsteht beim ersten Start: Datenbank,
                            Zertifikat und Einstellungen.

Einrichten (einmalig)
  1. Im Router dem PC eine feste IP-Adresse geben.
  2. Diesen Ordner z. B. nach C:\WealthFlowServer kopieren.
  3. start.cmd doppelklicken.
     Beim ersten Start fragt der Server nach dem Ordner für die
     zusätzliche Datendatei (leer lassen = keine) und legt dein Konto
     an (E-Mail, Name, Passwort mit mindestens 10 Zeichen).
     Windows fragt einmal "Zugriff zulassen?": nur "Private Netzwerke"
     anhaken. Ohne diese Freigabe erreichen Handy und andere PCs den
     Server nicht.

Benutzen
  Das Fenster zeigt die Adressen und den Fingerabdruck des Zertifikats.
  Solange das Fenster offen ist, läuft der Server.
  Fenster schließen oder Strg+C beendet ihn.

Gerät verbinden
  1. Im Server-Fenster Enter drücken. Es erscheint ein Kopplungscode
     (z. B. ABCD-EFGH-JKMN), 10 Minuten gültig für ein Gerät.
  2. In der App: Einstellungen > Server im Heimnetz > Mit Server
     verbinden. Adresse aus dem Fenster, Code, E-Mail und Passwort
     eingeben.
  Die App prüft dabei, dass sie wirklich mit diesem PC spricht, und
  akzeptiert danach nur noch dessen Zertifikat.
  3. Die App zeigt, welche Daten sie überträgt. Nach "Übertragen"
     gleicht sie automatisch ab: beim Start, nach Änderungen und alle
     5 Minuten. Ist der PC aus, arbeitet sie normal weiter.

Im Browser
  Eine Adresse aus dem Fenster im Browser öffnen, z. B.
  https://192.168.178.20:8443
  Der Browser warnt beim ersten Mal, weil das Zertifikat vom Server
  selbst stammt. Vorher den Fingerabdruck vergleichen (im Browser beim
  Schloss/Warnsymbol > Zertifikat > SHA-256), dann "Weiter" wählen.
  Danach wie in der App mit einem Kopplungscode verbinden.

Befehle im Fenster
  Enter     neuer Kopplungscode
  b         weiteres Benutzerkonto anlegen (z. B. für Tobias)
  g         gekoppelte Geräte anzeigen
  e <Nr>    Gerät entfernen
  h         Hilfe

Entfernen
  Ordner löschen. Die von Windows gespeicherte Firewall-Freigabe kann
  unter "Windows-Sicherheit > Firewall- & Netzwerkschutz > Zugriff von
  Apps durch die Firewall zulassen" gelöscht werden; ohne das Programm
  ist sie wirkungslos.

Sicherheit
  Der Server spricht nur HTTPS mit eigenem Zertifikat. Im Router keine
  Portfreigabe einrichten, damit er nur im Heimnetz erreichbar bleibt.
